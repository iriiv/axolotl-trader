# 🦎 Аксолотль-трейдер: Биржевые хроники

Пиксельная мобильная игра, которая учит понимать рынок на **реальных данных МосБиржи**
(открытый [MOEX ISS API](https://www.moex.com/iss/)). Маскот — аксолотль. MVP: 5 раундов,
лидерборд на SQLite, React-фронт под WebView/тач-устройства.

## Что это

Игра показывает настоящие исторические события (сераундированные подсказками), а ты:
1. Читаешь новостную ленту прошлого
2. Угадываешь, о какой компании речь и в каком году это было
3. Смотришь график акции до «дня решения» и делаешь ставку: ▲ вверх или ▼ вниз
4. Смотришь анимированный ревил настоящего движения + разбор: что произошло, почему и чему это учит

Раунды (все цифры — реальные, из истории торгов; 10 кейсов 2014→2023):

## Запуск

> 🌐 **Играть сейчас (телефон/десктоп):** https://iriiv.github.io/axolotl-trader/
> 📊 Презентация проекта: https://iriiv.github.io/axolotl-trader/presentation.html
> 🖼 Скриншоты этапов разработки: `docs/screenshots/`

```bash
# данные МосБиржи уже в server/data (2019→2026). Обновить: npm run fetch:moex
cd server && npm install && cd ..
cd client && npm install && cd ..
npm run dev        # API :4000 + UI :5173 (vite proxy)
```

Прод-сборка: `npm run build && npm start` → Express раздаёт client/dist на :4000.
Деплой на GitHub Pages — автоматически при пуше в main (`.github/workflows/pages.yml`).

## Архитектура

- `client/` — React 18 + Vite + TS. Пиксель-дизайн (дизайн-система в `client/src/design`)
- `server/` — Express + better-sqlite3. Контент раундов: `server/content/rounds.json`,
  котировки: `server/data/*.json`
- Оркестрация агентов (дизайнер/бек/фронт/тесты): см. [ORCHESTRATOR.md](ORCHESTRATOR.md)

## Концепция игры

- Очки: компания +150, год +100, направление +250 × скоростной бонус × комбо-множитель
- Лидерборд сохраняется в SQLite, боты для соревновательного духа прилагаются
- Каждый раунд заканчивается «разбором полётов»: что случилось на самом деле и какой урок извлечь
