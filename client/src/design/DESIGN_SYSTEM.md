# 📐 DESIGN_SYSTEM.md — конституция дизайн-системы «Пиксельный ночной океан»

Числовая спецификация для людей и роботов. Каждое правило проверяемо по коду:
файл-владелец указан в заголовке раздела. Этот документ главнее личных вкусов —
если правка противоречит цифре здесь, правка неверна (или сначала меняется глава
здесь). Общие принципы и API компонентов — в [README.md](./README.md).

`node scripts/e2e.mjs 1 2 3`, `e2e-hub.mjs`, `e2e-cosmetics.mjs` — все PASS.

## §1. Палитра (владелец: `tokens.css`)

Единственное место с hex — `:root` в tokens.css. Всё остальное — `var()` и
`color-mix(in srgb, var(--x) N%, var(--panel))`. **Сырые hex вне tokens.css и
матриц спрайтов запрещены.**

| Токен | Hex | Роль |
|---|---|---|
| `--bg-deep` | `#081020` | дно океана, низ градиента |
| `--bg` | `#0d1b2e` | фон экрана |
| `--panel` | `#16263e` | панели, карточки |
| `--panel-2` | `#1c3050` | приподнятые панели, грани |
| `--line` | `#2c4667` | внутренние линии, рамки ghost |
| `--ink` | `#eaf6ff` | основной текст |
| `--ink-dim` | `#8fb3d9` | вторичный текст |
| `--aqua` / `--aqua-hi` | `#4ce0c3` / `#6ff2dc` | главный акцент |
| `--pink` / `--pink-deep` / `--gill` | `#ffa7c9` / `#e26a9a` / `#ff5f8f` | тёплый акцент, «жабры», danger |
| `--gold` | `#ffd23e` | награды, монеты, daily |
| `--epic` | `#ff7ac8` | редкость epic |
| `--up` / `--up-deep` | `#43e97b` / `#1f9d55` | рост |
| `--down` / `--down-deep` | `#ff5f7a` / `#c22b4e` | падение |
| `--outline` | `#071018` | пиксельный контур всего |

**Допустимые сочетания текст/фон (контраст ≥ 4.5:1):**
`--ink` и `--ink-dim` на `--bg` / `--bg-deep` / `--panel` / `--panel-2`.
Акценты `--aqua`, `--gold`, `--up`, `--down`, `--pink` — как текст **только**
в дисплей-размере ≥15px или на тёмной подложке (панель/плашка); для мелкого
текста они запрещены. Заливка варианта кнопки несёт текст `--outline` (контраст
к aqua/gold/up/down/gill ≥ 7:1).

**Технические rgba (единственные вне палитры, владелец tokens.css):**
световая грань кнопок `--btn-light: rgba(255,255,255,.14)` и
`--btn-shade: rgba(0,0,0,.22)` — см. §5. Никаких других rgba-цветов в коде.

## §2. Шрифтовая шкала (владельцы: tokens.css, ui.css)

| Шрифт | Размеры | Веса | letter-spacing | Где |
|---|---|---|---|---|
| **Tiny5** (`.display`) | 15 · 20 · 25 · 30 · 35 px (шаг 5) | **только 400** | 0.05–0.1em | заголовки, цифры, плашки |
| **Tiny5**, кнопки | 16 · 18 · 20 px | 400 | 0.05em | подписи PixelButton md/lg/xl — единственное расширение шкалы |
| **Golos Text** | 13 · 15 · 17 · 20 px | 400 / 500 / 600 | 0–0.08em | основной текст, подписи, хинты |
| Golos, микро | 13 px | 400/500 | 0–0.1em | подписи таб-бара (≤340px — 12px), хинты, дисклеймеры |

- Иные размеры **запрещены**. Иерархию строим размером и цветом, не весом.
- У Tiny5 нет жирного: `font-weight: отличное от 400` для display — ошибка.
- Глифов `₽ ▲ ▼ ✓ ×` в Tiny5 нет — стрелки и крестик только SVG-иконками.

## §3. Сетка и отступы (владельцы: tokens.css, screens.css)

- База **4px**. Допустимые шаги: **4 / 8 / 12 / 16 / 20 / 24 / 32**.
- Экранные поля `.app`: **14px** по бокам (+safe-area сверху/снизу).
- Вертикальный gap между секциями экрана: **14px** (compact ≤700px высоты: 10px).
- Внутренние паддинги карточек: 14–16px; кнопок: см. §5.
- Ровно один скролл-контейнер на экран (`.scr-main`, `.hub-section`); документ
  не скроллится никогда (проверка `noscroll` в e2e).

---

## §4. Кнопки — общие правила

- Тап-таргет **≥ 44×44**; текст-кнопки — высота **≥ 52px**.
- `:active` — быстрый перенос в тень `--dur-fast` `--ease-out`, возврат —
  пружиной `--dur-mid` `--ease-spring`. Hover-обязательных состояний нет
  (кроме ghost на устройствах с мышью).
- Кнопка сама играет `sfx.tap()` + `haptic.tap()` (кроме disabled).

## §5. PixelButton (владельцы: ui.tsx / ui.css)

| Параметр | md | lg | xl |
|---|---|---|---|
| высота | **52px** | **60px** | **68px** |
| шрифт (display) | **16px** | **18px** | **20px** |
| паддинги | **16px** | **20px** | **24px** |
| ступень-тень | **4px** | **5px** | **6px** (`--shadow-step-md/lg/xl`) |
| нажатие translate | **3px** | **4px** | **5px** |

Конструкция послойно:

1. **Рамка** `3px solid var(--outline)`, радиус 0.
2. **Верхняя грань** — жёсткая двухступенчатая заливка:
   `linear-gradient(180deg, color-mix(in srgb, var(--btn-bg) 82%, white) 0 50%, var(--btn-bg) 50% 100%)`
   — резкий стоп 50/50, **не** плавный градиент.
3. **Внутренняя световая линия**: `inset 0 2px 0 var(--btn-light)` сверху +
   `inset 0 -2px 0 var(--btn-shade)` снизу — «объёмная» NES-кнопка.
4. **Ступень-тень** цветом `var(--outline)` (таблица выше).
5. **`:active`** — `translate(press)` + тень `1px 1px 0`, световые линии
   остаются; возврат пружиной.

Варианты (только они задают цвет): `primary` = aqua, `danger` = gill,
`gold` = gold, `up` = up, `down` = down (up/down автоматически получают ▲/▼),
текст во всех — `--outline`.

**ghost:** без заливки и световых граней; рамка `2px var(--line)`, текст
`--ink`, тень `2px`; hover/active — рамка загорается `--aqua`.

**Иерархия в хабе:** главная CTA — `xl primary`; вторичные — `lg`
(gold для daily, ghost для лидерборда); в модалках — `lg`; в дебаг-гриде — `md`.

## §6. OptionButton (владелец: ui.css)

Та же объёмная схема в панельных тонах: рамка 3px, грань
`panel-2 → panel` (стоп 50/50), световая линия (§1 rgba), ступень 4px,
высота ≥ 68px. Чип-буква 44×44 — мини-кнопка семейства (aqua-грань, рамка 2px,
шрифт display 20px). Состояния: `selected` — рамка-вкладка 2px aqua;
`correct` — заливка up + пружинный pulse; `wrong` — заливка down + тряска;
`muted` — 42% прозрачности, некликабелен.

## §7. Иконки (владелец: icons.tsx)

- Сетки: **12×12** (служебные знаки) или **14×14** (навигация и предметы:
  user, calendar, shirt, chest, play, coin, book, trophy, fire, clock, tv, lock).
- Заполненные пиксели, не «паутинка»: каждая деталь **≥ 2 юнита** толщиной.
- Рендер: параметр `size`; **от 24px** для самостоятельных иконок,
  **22px** в кнопках (xl — 24px), **30px** в таб-баре, 34px в ▶.
- Рисование матрицами строк (`#`/`.`), `shapeRendering="crispEdges"`,
  цвет — `currentColor`. Новые иконки — сначала сетка, потом матрица.

## §8. Таб-бар хаба (владелец: hub.css / HubScreen.tsx)

- Высота **60px**, 5 равных колонок, поля 4px, верхняя линия 2px `--line`.
- Иконки **30px**, центры всех иконок на одной вертикальной линии;
  подпись 13px display под плашкой.
- Активная вкладка — плашка **40×36**, рамка **2px aqua**, фон
  `color-mix(aqua 16%, panel)`, ступень 2px; в покое рамка прозрачна
  (плашка всегда занимает место — без прыжков иконки).
- Счётчик гардероба **N/23** — золотой бейдж в правом верхнем углу плашки.
- Центральная **▶ — 72px**, октагон `clip-path` (30%/70%), та же кнопочная
  конструкция, что §5: рамка-слой 3px `--outline` + ступень-тень **6px** +
  двухступенчатая грань + световая линия (3px). Приподнята над баром
  (translate −18px). Нажатие — перенос в тень на 5px. Активная секция —
  грань gold. Это единственный допустимый «радиус» в системе.

## §9. Карточки (владелец: ui.css)

- Рамка **3px** `--outline`, ступень-тень **5px** (`--shadow-step-lg`), радиус 0.
- Заголовок — плашка с «ушками»-квадратиками 6×6 цвета акцента.
- Заклёпки акцента 4×4 по углам, дизеринг-полоска сверху.
- Акценты: aqua / gold / pink / up / down — только рамки и плашки, не текст <15px.

---

## §10. Тап-таргеты и жесты

- Любой интерактив ≥ **44×44** (кнопки текстовые ≥ 52px, см. §4–5).
- Кнопка закрытия модалки 52×52; крестик coach «×» 44×44.
- Подсказки онбординга **не перехватывают** клики: `pointer-events: none`
  у плашки, `auto` — только у её кнопок (§12).

## §11. Анимации (владелец: tokens.css)

- Анимируем только **transform** и **opacity** (layout не дёргаем).
- Кривые: `--ease-spring` (overshoot), `--ease-out` (нажатия), `--ease-inout`
  (циклы). Длительности: **180 / 320 / 500 мс** (`--dur-fast/mid/slow`).
- Пружины framer-motion для экранов: `{stiffness: 320, damping: 30}`.
- `prefers-reduced-motion` гасит CSS-анимации и уважается MotionConfig.
- Запрещены blur-тени, плавные градиенты на гранях кнопок (только стоп 50/50),
  синтетический bold Tiny5.

## §12. Онбординг CoachTip (владельцы: ui.tsx, HubScreen.tsx)

- Тёмная плашка `color-mix(outline 78%, panel)`, рамка 2px aqua, ступень 3px,
  хвостик-стрелка (лесенка clip-path), кнопки «Дальше» и «×», счётчик «1/3».
- 3 шага первого запуска (маскот → ▶ → гардероб), только при чистом профиле:
  нет `ax_nick` И нет флага `ax_onboarded` (storage.ts).
- Шаг 1 закрывается тапом в любом месте (пассивный listener pointerdown —
  тап проходит к элементу под подсказкой). Любое закрытие пишет флаг навсегда.
- Тексты шагов — константа `COACH_STEPS` в HubScreen.

## §13. Do / Don't

**Do:**
- Цвет — только `var()`/`color-mix`; свет кнопки — только `--btn-light/--btn-shade`.
- Иконку в навигации рисовать на 14×14 с деталями ≥2 юнита, рендер ≥24px.
- Нажатие кнопки — перенос в тень (translate + тень 1px), возврат пружиной.
- Размеры шрифта/отступы брать строго из шкал §2–3.
- Тень — только ступени `--shadow-*` / `--shadow-step-*` цветом outline.

**Don't:**
- Не сжимать иконку ниже 24px (в таб-баре 30px) и не масштабировать спрайты
  с искажением сетки.
- Не использовать blur-тени, полупрозрачные размытия и плавные градиенты
  на гранях кнопок.
- Не менять размеры/веса вне шкал §2 и не «жирнить» Tiny5.
- Не вводить border-radius (кроме октагона ▶) и не скруглять спрайты.
- Не размещать акцентные цвета мелким текстом (<15px) на тёмном фоне.
- Не делать hover-обязательные состояния (тач-first) и не анимировать
  свойства layout (width/height/top/left).
- Не перекрывать клики оверлеями: подсказки и декор — `pointer-events: none`.
