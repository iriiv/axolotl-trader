# 🎩 Спецификация: экономика, сундуки, Daily (v1.1)

> Порядок: 🎨 дизайнер (ассеты) → 💻 фронтендер (логика) → 🧪 тесты → деплой

## 1. Валюта — «пузырьки» ₽

Начисление за партию (кампания 10 раундов):
| Событие | Монеты |
|---|---|
| компания угадана | +15 |
| год угадан | +10 |
| направление верно | +40 |
| раунд завершён (любой исход) | +10 |
| партия целиком | +30 |

Идеальная партия ≈ 1050 монет. Daily-кейс (1 раунд): те же ставки ×1, бонус за стрик: +10×min(streak,7).

Дубликат из сундука → компенсация монетами: common 20 · rare 60 · epic 200 · legend 500.

Монеты тратятся ТОЛЬКО на дооткрытие сундуков в «Гардеробе» (без реальных денег, всё локально): жемчужный 150, золотой 400.

## 2. Сундуки и дроп

| Сундук | Откуда | Шансы common/rare/epic/legend |
|---|---|---|
| Деревянный | после партии кампании | 70/25/5/0 |
| Жемчужный | за Daily-кейс дня (раз в день) | 55/32/12/1 |
| Золотой | стрик 7 дней подряд (авто) или за 400 монет | 40/40/18/2 |

- Дроп: предмет случайного ТИПА (скин/шляпа/аксессуар равновероятно) и случайной РЕДКОСТИ по таблице, затем случайный предмет этой редкости из каталога (не стартовые скины).
- Если всё этой редкости уже есть → дубликат самого редкого недостающего... нет, просто дубликат случайного (компенсация монетами).
- Гарантия сочувствия (pity): из 5 деревянных подряд хотя бы один rare+.
- RNG: Math.random (не соревновательный режим), сид не нужен.

## 3. Инвентарь и экипировка (localStorage, ключи `ax_inv`, `ax_equip`, `ax_coins`)

- `ax_inv`: string[] id предметов; старт: ['skin-classic']
- `ax_equip`: {skin:'skin-classic', hat:null, acc:null} — надетое отображается ВЕЗДЕ, где живёт аксолотль (титул, ревил, саммари, шапка hедера НЕ трогаем)
- «Гардероб» — экран из титула (кнопка с иконкой футболки + баланс монет), табы по типам, тап по карточке — экипировать/снять, лктый тап не нужен.

## 4. Daily Challenge («Хроника дня»)

- Кейс дня = rounds[hash(dateKey) % rounds.length], dateKey = локальная дата YYYY-MM-DD
- Один прогон в день; кнопка на титуле: «ХРОНИКА ДНЯ №N» + стрик-огонь; после прохождения до вечера — плашка «Завтра новая»
- Стрик: +1 за пройденный кейс дня; пропуск дня → сброс (заморозок в v1.1 нет)
- По завершении: DailyResultCard (компонент дизайнера) + сундук жемчужный + шеринг-текст:

```
🦎 Биржевые хроники — День №N
Компания ✓ · Год ✗ · Ставка ▲✓
Стрик: X 🔥
Твой ход: <url>
```

- История дней: `ax_daily`: {lastDateKey, streak, bestStreak, played: {dateKey: {ok3: boolean[]}}}

## 5. Интеграция в существующий флоу

1. Титул: надетый аксолотль + кнопки «ХРОНИКА ДНЯ №N» (gold, с иконкой календаря) и «ГАРДЕРОБ» (ghost, иконка футболки + баланс монет с иконкой монеты)
2. После Summary кампании → ChestScreen (деревянный) → гардероб или в меню
3. Daily-режим: тот же игровой флоу для одного раунда → DailyResultCard → сундук жемчужный → титул
4. Ревил/саммари/титул: аксолотль в экипировке
5. Профиль-мини в титуле: стрик + монеты + счётчик предметов (N/24)

## 6. Тест-кейсы (для 🧪)

- Дубликат → монеты начислены, плашка показана
- Pity: 4 wooden без rare+ → 5-й гарантирует
- Daily нельзя пройти дважды в день (по локальной дате)
- Стрик сбрасывается при пропуске дня (эмуляция даты: тест-хук `__setDateKey`)
- Экипировка сохраняется между сессиями и видна на всех экранах с аксолотлем
- Носимое не удаляется из инвентаря
- 320×568: гардероб без скролла документа
